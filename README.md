# 📊 PhonePe Transaction Analytics Dashboard

An interactive UPI transaction analytics project built using **Python, SQL, Excel, and Power BI**.

> **Note:** The dataset used in this project is completely synthetic and generated using Python/Faker for learning and portfolio purposes. It is not real PhonePe data.

## 🚀 Project Overview

This project analyzes UPI transactions to understand:

- Transaction trends and performance
- Customer segments and behavior
- Merchant and category performance
- Payment patterns
- Suspicious transactions and anomalies

## 🛠️ Tech Stack

- **Python & Faker** — Synthetic data generation
- **SQL (MySQL)** — Data analysis
- **Excel** — Data preparation
- **Power BI** — Interactive dashboard & visualization
- **DAX** — KPIs and analytical measures
